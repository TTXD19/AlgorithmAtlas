**二分搜尋**只需要一個前提：資料對於你要問的問題是**單調的**。有序陣列是最常見的形式，但本質是「某個條件在前半全部不成立、後半全部成立」。看中間那個元素，就知道答案在左半還是右半，扔掉另一半。每次砍一半，n 個元素 **⌈log₂(n+1)⌉** 次就到底，這是 **O(log n)** 的來源。不過要真的做到 O(log n)，還得能直接跳到中間那格：陣列可以，鏈結串列光是走到中間就要 O(n)。

最常見的錯不是想法錯，是**邊界寫錯**：`hi` 該是 `n` 還是 `n-1`、迴圈是 `<` 還是 `<=`、更新是 `mid` 還是 `mid+1`，三者必須配套。記住兩套寫法就夠。**閉區間** `[lo, hi]`：`hi = n-1`，`while lo <= hi`，兩邊都用 `mid ± 1` 排除，找到就回傳，適合「找任一個等於 target 的」。**半開區間** `[lo, hi)`：`hi = n`，`while lo < hi`，條件成立時 `hi = mid`（mid 可能是答案，留著），不成立時 `lo = mid + 1`（mid 確定不是），迴圈結束時 `lo == hi` 就是答案，適合「找第一個滿足條件的位置」。

**lower_bound** 是「第一個 `≥ target` 的位置」，**upper_bound** 是「第一個 `> target` 的位置」，程式碼只差一個等號。它們回傳的是 `0..n` 之間的**插入位置**，target 不存在時不會回傳 −1，而是「如果要插入應該放哪」，所以 `hi` 必須能等於 `n`。有了這兩個，很多問題直接組合：target 存在嗎，看 `lower < n and a[lower] == target`；出現幾次，`upper − lower`；最後一次出現的位置（先確認存在），`upper − 1`；「最後一個 `≤ target`」，`upper − 1`；「最後一個 `< target`」，`lower − 1`。

半開區間為什麼不會無限迴圈：`mid = (lo + hi) // 2` 向下取整，所以 `mid < hi`，`hi = mid` 一定縮小；`lo = mid + 1` 一定變大。若你寫成「`lo = mid`」這種不排除 mid 的更新，`lo` 和 `hi` 相鄰時 mid 會等於 lo，就卡死了。這時要改成向上取整 `mid = (lo + hi + 1) // 2`，另一邊配 `hi = mid - 1`。C++ 裡 `lo + hi` 可能溢位，寫 `lo + (hi - lo) / 2`。
