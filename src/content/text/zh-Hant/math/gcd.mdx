**輾轉相除法**（歐幾里得演算法）只靠一個等式：`gcd(a, b) = gcd(b, a mod b)`。理由是 `a mod b = a − q·b`：任何同時整除 a 和 b 的數，一定也整除 `a − q·b`；反過來，同時整除 b 和餘數 r 的數，也整除 `a = q·b + r`。兩組數的公因數集合完全相同，最大的那個當然也相同。每做一次，數字就變小，直到餘數為 0，而 `gcd(g, 0) = g`。整個過程從不需要知道 a、b 的質因數，這是它比「分解質因數再取共同部分」快得多的原因。

為什麼快：看連續兩步 `(a, b) → (b, r) → (r, r′)`。若 `b ≤ a/2`，則 `r < b ≤ a/2`；若 `b > a/2`，商只能是 1，`r = a − b < a/2`。所以**每兩步第一個數至少減半**，除法次數是 **O(log min(a, b))**。最壞情況是相鄰的費氏數，每次商都是 1、縮得最慢，例如 `gcd(89, 55)` 要 9 次除法。迴圈版只用兩個變數，空間 **O(1)**；遞迴版要 O(log) 的呼叫堆疊。最小公倍數靠 `gcd(a, b) × lcm(a, b) = a × b` 得到，寫成 `a / gcd × b`。多個數就兩兩折疊，總共 O(n log M)，M 是最大值；gcd 一旦變成 1 就可以提前停。

**擴展歐幾里得**在求 gcd 的同時找出整數 x、y 使 `ax + by = gcd(a, b)`，這組解一定存在（**Bézout 等式**）。遞迴寫法：假設已經求出 `b·x′ + (a mod b)·y′ = g`，把 `a mod b = a − ⌊a/b⌋·b` 代進去整理，得到 `x = y′`、`y = x′ − ⌊a/b⌋·y′`。兩個直接的推論：`ax + by = c` 有整數解**若且唯若 g 整除 c**；當 `gcd(a, m) = 1` 時，`ax + my = 1` 兩邊取模 m 得到 `ax ≡ 1`，x 就是 a 的**模反元素**。Modular Arithmetic 那篇用費馬小定理加快速冪求反元素，但那要求模數是質數；擴展歐幾里得只要求互質。

常見的坑：用減法版 `gcd(a − b, b)` 代替取餘數，`gcd(10⁹, 1)` 要減十億次；C++ 的 `%` 結果跟著被除數的正負號，負數要先取絕對值（C++17 的 `std::gcd` 已經處理好）；lcm 寫成 `a * b / gcd` 會在除之前溢位，而且 a、b 有 0 時會除以 0；擴展歐幾里得算出的 x 常是負的，當反元素用之前要 `(x % m + m) % m`。題目裡看到分數，通常存成約分後的 `(分子, 分母)` 並把負號固定放在分子，就不會有浮點誤差，也能直接拿來當雜湊表的 key。
