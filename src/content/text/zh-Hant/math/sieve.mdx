判斷一個數是不是質數，最直接的方法是**試除**到 √x，但要列出 N 以內所有質數時，逐個試除是 O(N√N)。**埃拉托斯特尼篩法**反過來做：不去檢查每個數，而是讓每個質數去**劃掉自己的倍數**。一開始把 2 到 N 都當成可能是質數，由小到大掃，遇到第一個還沒被劃掉的數 p，它一定是質數，因為如果它有比自己小的質因數，早就被那個質因數劃掉了；接著把 p 的倍數全部劃掉，再找下一個。

兩個讓它更快的觀察。第一，p 的倍數**從 p² 開始劃**就好：比 p² 小的倍數是 `p·k`，其中 k < p，k 的質因數比 p 小，這個數在處理那個更小的質數時已經劃掉了。第二，**p² > N 就可以停**：任何不超過 N 的合數都能寫成 `a·b` 且 a ≤ b，於是 `a² ≤ N`，它一定有一個不超過 √N 的質因數，早就被劃掉了。所以外層迴圈只跑到 √N，之後陣列裡還沒被劃掉的數全是質數。

複雜度：質數 p 要劃大約 N/p 次，總次數是 `N/2 + N/3 + N/5 + N/7 + …`，而質數倒數的總和只以 log log N 的速度成長，所以時間 **O(N log log N)**。N = 10⁷ 時 ln ln N 還不到 3，實際上幾乎是線性的。空間是一個長度 N + 1 的布林陣列，**O(N)**。兩個常用的變形：**線性篩**讓每個合數只被它的最小質因數劃掉一次，嚴格 O(N)，還順便得到**最小質因數表**，之後分解任何 x ≤ N 都只要 O(log x)；**區間篩**先求出 √R 以內的質數，再用它們劃掉區間 [L, R] 裡的倍數，R 大到 10¹² 也只需要 √R 加上區間長度的記憶體。

常見的坑：0 和 1 忘了設成非質數；陣列開成 N 而不是 N + 1；C++ 裡 `p * p` 在 N 接近 2³¹ 時會溢位，寫成 `p <= n / p`；每個質數都從 2p 開始劃雖然正確，但白白多走很多已經劃掉的數；區間篩的起點要取 p² 和「區間內第一個 p 的倍數」兩者較大的，否則 L 很小時會把 p 本身劃掉。和鄰近課程的關係：上一篇 GCD 不需要分解質因數，而篩法正好提供大量分解的工具；下一篇 Modular Arithmetic 常用質數當模數，費馬小定理也要求模數是質數；如果只是要判斷一個 10¹⁸ 等級的數是不是質數，應該用 Miller–Rabin 這類機率測試，而不是篩法。
