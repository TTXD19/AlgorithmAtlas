樹是**沒有環的連通圖**，但更直覺的說法是：一個**根**節點，底下掛著零個或多個**子樹**，每棵子樹又是一棵樹。這個「自己包含自己」的定義，就是為什麼樹的演算法幾乎都用遞迴寫。二元樹是每個節點最多兩個子節點的樹，分成**左子樹**與**右子樹**，左右有別。

幾個一定要分清楚的詞。**深度**是從根往下到這個節點的邊數，根的深度是 0。**高度**是從這個節點往下到最遠葉節點的邊數，葉的高度是 0；樹的高度就是根的高度。**葉節點**沒有子節點；**內部節點**至少有一個。深度由上往下數，高度由下往上數，兩者方向相反。

**完全二元樹**是每一層都填滿、只有最後一層可以不滿而且靠左的樹。它有一個很好的性質：用層序把節點編號 0, 1, 2, …，索引 i 的父節點在 `(i − 1) / 2`，子節點在 `2i + 1` 與 `2i + 2`，不會有空洞。堆積就是靠這點用陣列存的。**滿二元樹**更嚴格：每個節點要嘛沒有子節點、要嘛剛好兩個。

n 個節點的二元樹，高度最小是 ⌊log₂ n⌋（每層都塞滿），最大是 n − 1（退化成鏈）。之後很多結構的複雜度寫成 O(h)，h 是高度；能不能保持 h ≈ log n，就是「平衡」那一篇的主題。
